Scene and show-file channels use bands of 8 values (0-7 = none, 8-15 = item 1…) and act when the value changes. The other channels act on the effect an output's scene plays, and keep its own value at 0: speed, parameter, generator, colours, phaser, Block / Groups / Wings — and the effect itself, picked in the bank by bands of 8. A scene channel with a partial output group plays its scene on those outputs only.
